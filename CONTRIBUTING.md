# Contributing

Thanks for your interest in the Call Center Village voice security training.
Corrections matter most here: this material describes fast-moving tools, and a
model that was state of the art last quarter may be frozen, relicensed or gone
today.

## Licensing of contributions

By opening a pull request you agree to license your contribution under the same
terms as the material it touches, and you confirm you have the right to do so:

- **Code** — MIT, per [`LICENSE`](LICENSE)
- **Training content** — CC BY-SA 4.0, per [`LICENSE-CONTENT`](LICENSE-CONTENT)

[`LICENSING.md`](LICENSING.md) explains which is which. Do not contribute text,
images, audio or code copied from somewhere else unless its license permits it
and you say so in the pull request — including material generated by a tool
whose output carries restrictions.

Do not add or modify Call Center Village branding (the name, the CCV logo, the
OG card design). Those are not covered by either license.

## What to include with a change

- **Facts about tools and models** — a source link, and a date. Claims about
  licenses, benchmark standings or whether a project is maintained go stale;
  `src/modules/appendix/data/resources.js` keeps archive links for this reason.
- **New quiz questions** — one clearly correct answer and an explanation that
  teaches something, not just "correct".
- **New sections or modules** — `netlify.toml` needs a rewrite rule,
  `public/sitemap.xml` needs the routes, and `src/siteMeta.js` plus
  `scripts/build-og-images.py` need a social card.
  `src/test/staticFiles.test.js` fails if you forget any of them.

## Development

```bash
pnpm install
pnpm dev        # http://localhost:5173
pnpm lint
pnpm test
pnpm build      # client + SSR + prerender of every route
```

CI runs lint, tests and a full build on every pull request. Regenerated assets
(`public/fonts/*.woff2`, `public/images/og-*.png`) are committed — Netlify does
not run Python — so commit them alongside the change that requires them.
`pnpm build` also rewrites `public/.well-known/security.txt` with a fresh
`Expires` date; commit that too when it changes.

## House style

- No CSS files. Styles are inline and colours come from `src/components/colors.js`.
- Don't import from `src/components/index.js` in eagerly-loaded code — the
  barrel pulls `wavesurfer.js` into the initial payload.
- Anything rendered at build time must tolerate having no `window`.
- Comments explain why a thing is the way it is, not what the line does.

## Reporting a problem

Factual errors, broken links and accessibility issues are welcome as issues. For
anything security-sensitive, see [`SECURITY.md`](SECURITY.md) instead of opening
a public issue.
